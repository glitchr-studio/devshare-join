DevShare support

DevShare shares the websites a developer is building on their Mac, for a few minutes, with guests anywhere. The Mac app shares; the iPhone and iPad app, and DevShare on another computer, join.

Getting help

Write to support@glitchr.io. Say which app (Mac, or iPhone and iPad), its version, and what you saw. Answers come from France, on working days.

Common questions

The app says “no connection”. The device has neither Wi‑Fi nor mobile data. Connect it; the host's Mac can be on any network.

“The session is over”. Sessions last the time the host chose, and end on their own. If the host starts it again under the same invitation, “Join again” takes you back in without scanning.

I have a code but no QR code or link. A code typed by hand needs a join server, set under Advanced settings in the app. Without one, scan the QR code the host's Mac shows, or open the link they send.

A page will not open. Only the addresses the host ticked are reachable, and only while the session lasts. Ask the host whether the project is running and shared.

Can my guests reach me when I am not on their network? Yes. When no direct path exists the connection goes through a relay, by default one of the public relays of number 0, or one you run yourself: see devshare-relay.
